# 📝 Notes App

A full-stack Notes Application that allows users to create, update, and delete notes easily. This project demonstrates CRUD operations and the integration of frontend and backend technologies to manage notes efficiently.

## 🚀 Features

* Create new notes
* Update/Edit existing notes
* Delete notes
* Search Fubctionality
* user-friendly interface
* Full CRUD functionality

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript / React
* Backend: Node.js, Express.js
* Database: MongoDB
